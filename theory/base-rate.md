# Base Rate Anchoring

**Core Question:** Before looking at ANY stock-specific evidence, what is the historical probability that a theory like this is correct?

This step MUST run BEFORE any other analysis. The human brain anchors to the first number it sees — if we start with stock-specific evidence, we'll be biased by it. The base rate is our prior.

## Why This Matters

Base rate neglect is one of the most documented cognitive biases in investing. When someone says "NVDA has a monopoly and will dominate for 3 years," the natural instinct is to analyze NVDA. The disciplined instinct is to first ask: "historically, how often do technology monopolies last 3+ years?"

If the base rate is 40%, that's your STARTING point. Evidence can move it up or down, but you don't start at 50/50 or wherever your gut puts it.

## Process

### Step 1: Classify the Theory
What TYPE of claim is this theory making? Categories:

- **Monopoly/dominance persistence** — "company X will maintain market dominance for N years"
  - Historical base rate: ~30-50% for 3+ years in tech (depends on barriers)
- **Growth continuation** — "company X will maintain >Y% growth for N quarters"
  - Historical base rate: ~25-35% for high-growth tech continuing 2+ years
- **Undervaluation** — "market is mispricing company X, fair value is Y% higher"
  - Historical base rate: depends on methodology, but most "undervalued" claims don't materialize
- **Sector/macro thesis** — "sector X will outperform because of macro trend Y"
  - Historical base rate: ~40-50% for well-reasoned sector calls
- **Event-driven** — "event X will happen, benefiting company Y"
  - Historical base rate: varies wildly by event type

### Step 2: Search for the Base Rate
WebSearch for: "historical success rate of [theory type] in [sector]" and "how often do [specific claim type] predictions succeed"

Look for:
- Academic studies on prediction accuracy
- Historical examples of similar claims
- How often has THIS company's sector seen theories like this be right?

### Step 3: Establish and Document
```
Base Rate Classification: [theory type]
Historical Base Rate: X%
Sources: [where this number comes from]
Key adjustment factors: [anything that makes this case unusual vs the reference class]
Starting Prior: X% (may differ from raw base rate if strong adjustment factors exist)
```

## Critical Rule

If you CANNOT find a reliable base rate, default to the "outside view" heuristic: assume 30-40% as a prior for any specific stock thesis. Most theses are wrong. This is humbling but statistically accurate.

NEVER start with a prior above 50% unless you have strong empirical evidence for the base rate itself.
