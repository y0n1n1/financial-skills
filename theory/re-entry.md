# Re-Entry Protocol

When a position is closed and conditions later improve.

## Trigger
- Price reaches entry level from "What Would Change This"
- OR parameter update materially improves EV

## Steps

### Step 1: Theory Still Valid?
- Has any theory point been falsified since exit?
- Is the demand chain intact?
- Is the competitive moat assessment unchanged?
- If ANY point falsified: FULL new gauntlet required

### Step 2: Abbreviated Gauntlet (4 hours vs 12)
- Phase 0: Update regime only
- Phase 1: Reuse prior, update for new analogues only
- Phase 2: Update evidence chain with NEW data only (since last analysis)
- Phase 3: Re-run MC with updated parameters
- Skip: Full lens analysis (use previous unless >6mo old / alpha decay expired)

### Step 3: Compare New vs Original EV
- If improvement driven by PRICE DECLINE: valid entry (same thesis, better price)
- If improvement driven by THESIS CHANGE: this is a NEW position, full gauntlet required

### Step 4: New Theory Card
A position entered at $145 is a different bet than one at $178.
Create a NEW theory card ID, not an update to the old one.
Separate cards = separate tracking = honest post-mortem for each entry point.
